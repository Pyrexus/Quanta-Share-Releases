# Quanta Share

**Big files. Small effort.**

The official public distribution channel for signed Quanta Share Android releases.

[Download the latest release](https://github.com/Pyrexus/Quanta-Share-Releases/releases/latest) · [Open Quanta Share](https://quanta-share.100coldice.workers.dev) · [API documentation](https://quanta-share.100coldice.workers.dev/docs)

## Share and keep your files

- Fast, continuous uploads with automatic recovery when a connection drops.
- Individual links and collections, with optional expiry and one-time access.
- A personal Quanta Cloud library with folders, search, previews, and downloads.
- In-app release notifications, Android Download Manager, and verified APK updates.
- Clear light and dark themes, accessible controls, and live transfer progress.

## Install or update

1. Open the [latest release](https://github.com/Pyrexus/Quanta-Share-Releases/releases/latest) and download **Quanta-Share.apk**.
2. Open the APK and follow Android's installation prompts. Allow installation from the app you used to download it if requested.
3. Install over your existing Quanta Share installation to retain its data and settings. No uninstall is needed.

Requires Android 8.0 or later. Version 1.4.0 enables in-app notifications for future releases; Android controls notification and installation permissions.

## Release integrity

Release assets are signed with the established Quanta Share release certificate. Each release includes the APK's SHA-256 checksum. The app checks package identity, version, signing certificate, and a published digest when available before offering an update to Android's package installer.

This repository contains release information and application packages. It does not contain the private development repositories or user files.
